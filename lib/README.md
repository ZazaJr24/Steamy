# Steamy relay client binary

The app builds against the supplied Steamy.RelayClient.dll. The implementation
source is maintained locally by the owner. This DLL retains the repository's MIT
license. It contains no provider key, SSH password or private SSH key.

It is ordinary .NET code and can be decompiled. Keeping implementation source out
of the current tree does not establish original-app-only authorization. Shared
provider credentials and upstream processing remain exclusively on the VPS.

Earlier public commits or external copies may retain an earlier implementation.
Removing files from the current tree cannot retract copies already obtained.
