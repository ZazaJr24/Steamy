# Google Sans

Source: [Google Fonts' Google Sans family](https://github.com/google/fonts/tree/main/ofl/googlesans), downloaded 2026-10-07. The original variable font is retained as `GoogleSans-variable.ttf`.

The four embedded static instances use weights 400, 500, 600 and 700, optical size 18 and grade 0. They were instantiated with fontTools 4.66.1; static instances support WPF's native font renderer without relying on installed fonts. Family/style name records identify Google Sans and the corresponding weight.

The accompanying SIL Open Font License is included in the application output. The font remains owned by its authors.
